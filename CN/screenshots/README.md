| 手册章节 | 需要补拍的界面 |
| --- | --- |
| `README.md` | 安全总览、侧边栏导航和账户入口 |
| `01-quickstart.md` | 当前配置向导、监控状态、脚本威胁详情与信任操作 |
| `02-dashboard.md` | 安全总览、脚本/Agent 趋势、侧栏状态球与开关、Agent 监控详情 |
| `03-first-analysis.md` | 三份示例脚本的实际规则/AI 进度、检出方式、风险与处置结果 |
| `04-monitoring.md` | 安全配置中的监控目录、自动发现的 RPA 目录、侧栏开关状态 |
| `05-security-log.md` | 威胁中心六个标签、脚本双栏、来源与意图、深度研判、导出菜单 |
