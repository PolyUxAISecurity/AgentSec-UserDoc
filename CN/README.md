## 什么是 AgentSec？

AgentSec 将本机规则检查与可选 AI 研判用于以下场景：

- 🔍 **自动扫描**：实时监测您电脑上的 RPA 脚本（UiPath、Python、PowerShell 等）
- 🛡️ **Agent 防护**：查看已接入 Agent 的活动，并对支持的外部工具调用进行检测和处置
- 🔎 **Dify 审计**：获取或导入工作流，定位凭据与敏感数据外发风险，复核整改结果
- 🚫 **脚本处置**：按检查结论和处置方式进行隔离、告警或人工复核
- 💬 **DeepIntent Agent**：解读风险、调用工具，并处理工作区中的脚本副本

先选择需要使用的场景，再按对应章节配置和查看结果。

## 应用界面导航

AgentSec 桌面端采用单页应用设计：

| 导航位置 | 入口 |
|---------|------|
| **安全仪表盘** | 安全总览、Agent 监控 |
| **威胁中心** | 脚本威胁列表、Agent 实时事件、Dify 工作流、历史记录、通知、安全沙箱 |
| **AgentSec Engine™** | 引擎、规则实验室、策略市场；高级模式可显示 DSL 规则 |
| **AI 助手** | 右下角悬浮按钮（或 `Ctrl+K` / `Cmd+K`） |
| **设置** | 侧边栏底部齿轮按钮 — 常规、安全配置、账户、更新、外观、版本说明 |

## 三种使用模式

AgentSec 支持三种运行模式，您可以根据实际情况选择：

| 模式 | 适用场景 | 需要什么 |
|------|---------|---------|
| **登录 AgentSec**（推荐） | 大多数用户 | 一个 AgentSec 账号（浏览器登录即可） |
| **内网部署** | 企业自建了 AgentSec 服务器 | 公司提供的服务器地址 + 账号 |
| **本地模式** | 不登录 AgentSec，使用本机规则扫描 | 无需模型；AI 功能可选配本机或远程模型 |

> 💡 **不确定选哪个？** 选「登录 AgentSec」即可，这是最简单的方式。

## 典型工作流程

1. 选择需要监控的 RPA 脚本目录。
2. 启动监控后，AgentSec 自动发现新增或修改的脚本。
3. 脚本先经过正则快速扫描，再按需进入 AI 深度分析。
4. 查看风险结论与实际处置；待确认的建议由用户复核后处理。
5. 用户在威胁中心查看详情，并按需信任、修复或重新分析。

## 支持检测的脚本类型

| 扩展名 | 脚本类型 | 常见来源 |
|--------|---------|---------|
| `.xaml` `.xmal` | UiPath 工作流 | UiPath Studio |
| `.py` | Python 脚本 | Python 自动化 |
| `.robot` | Robot Framework | 测试自动化 |
| `.bpmn` | BPMN 流程 | 流程建模工具 |
| `.ps1` | PowerShell 脚本 | Windows 系统管理 |
| `.vb` | VBScript 脚本 | 传统 Windows 自动化 |
