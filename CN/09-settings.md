# 设置与账户指南

> 设置页面用于管理 AgentSec 的所有配置：账户、AI 模型、监控目录、自动更新等。

---

## 打开设置

在左侧导航栏点击 **⚙ 设置**（齿轮图标），或点击侧边栏底部的齿轮按钮。

> 📸 **[截图位置]** `screenshots/settings-overview.png` — 设置页面全景

---

## 设置页面布局

设置页采用**左右分类导航**布局：

```
┌──────┬──────────────────────────────────┐
│ 常规  │                                  │
│ 账户  │   当前选中分类的设置内容            │
│ 更新  │                                  │
│ 外观  │   （右侧面板）                     │
│ 版本  │                                  │
├──────┴──────────────────────────────────┤
│         [所有配置共用一个保存按钮]         │
└─────────────────────────────────────────┘
```

### ⚡ 自动保存

AgentSec 支持**自动保存**。修改任何设置后，1-2 秒内会自动写入配置文件。底部保存条会显示状态：

| 状态 | 提示文字 |
|------|---------|
| 无改动 | 「所有配置共用一个保存按钮」 |
| 有未保存 | 「有未保存的更改」 |
| 保存中 | 「正在保存...」 |
| 已保存 | 「已保存」 |
| 出错 | 「保存出错: ...」 |

> 💡 自动保存适用于绝大多数改动。如果想要手动保存，也可以点击底部的「保存设置」按钮。

## 一、常规

> 📸 **[截图位置]** `screenshots/settings-general.png` — 常规设置截图

### 配置向导

点击 **「运行引导向导」** 可以重新运行首次配置向导。适合想要重新设置使用方式或监控目录的情况。

### 运行模式

| 模式 | 说明 |
|------|------|
| Local（离线本地） | 不连接任何服务端，AI 分析完全在本地完成 |
| Community（云端 SaaS） | 连接 AgentSec 云服务，AI 分析在云端处理 |
| On-Premise（内网部署） | 连接企业自建的 AgentSec 服务器 |

> 📸 **[截图位置]** `screenshots/settings-mode-selector.png` — 运行模式下拉选择

切换模式后，下方会显示对应的提示和配置项。

### 监控目录

支持**多目录同时监控**。可以添加多个文件夹路径，AgentSec 会同时监控所有目录中的 RPA 脚本。

### 开发者选项

- **启用 Debug 视图**：开启后侧边栏出现「Debug」入口，可查看实时分析日志流
- 仅在排查问题时需要开启

### 危险区域

**「重置所有数据」** 按钮会：
- 清空配置、Agent ID、分析历史、聊天记录、白名单
- 删除完成后应用自动退出
- 重新打开时如同首次安装

> ⚠️ 此操作不可撤销！

## 二、账户

> 📸 **[截图位置]** `screenshots/settings-account.png` — 账户设置截图

### 登录状态

#### 已登录

显示以下信息：

| 字段 | 说明 |
|------|------|
| 头像 | 根据邮箱自动生成的标识 |
| 邮箱 | 登录时使用的邮箱 |
| 组织 | 您所属的 AgentSec 组织（租户） |
| Agent ID | 当前机器的唯一标识 |
| 模型用量 | 组织的 AI 配额使用情况 |

点击 **「退出登录」** 可断开与服务端的连接。

#### 未登录

- 显示「连接控制台（登录）」按钮
- 如果是内网部署模式，需要先填写服务器地址

### 连接测试

点击 **「测试连接」** 可以验证服务端是否可达、登录凭证是否有效。

> 📸 **[截图位置]** `screenshots/settings-test-server.png` — 服务端连接测试结果

### 服务器地址

仅在 **On-Premise（内网部署）** 模式下显示。填写企业自建 AgentSec 服务器的地址（如 `https://agentsec.intra.acme.com`）。

### AI 模型配置（仅本地模式）

> 📸 **[截图位置]** `screenshots/settings-ai-model.png` — AI 模型设置截图

**登录模式（community / onpremise）：**
AI 模型由服务端统一管理，客户端无需配置。也可以通过侧边栏 **AgentSec Engine™ → AI 模型**查看当前生效的模型。

**本地模式（local）：**
需要自行配置以下内容：

| 设置项 | 说明 | 示例 |
|--------|------|------|
| 模型供应商 | 选择 AI 服务商 | OpenAI / Anthropic / Ollama / OpenAI 兼容 |
| 模型 | 模型名称 | `gpt-4o-mini` / `claude-sonnet-4-20250514` |
| API Key | 服务商的 API 密钥 | `sk-xxxx...`（Ollama 可留空） |
| Base URL | 自定义接口地址（Ollama / OpenAI 兼容时显示） | `http://localhost:11434/v1` |

### 测试 LLM 连接

点击 **「测试 LLM」** 按钮验证模型可用。测试会分两步：连通性检查（不消耗 token）和调用测试（消耗约 1 token）。

## 三、更新

> 📸 **[截图位置]** `screenshots/settings-updates.png` — 更新设置截图

### 自动检查更新

- **开关**：启用/禁用启动时和周期性的自动更新检查
- **默认**：启用，每 6 小时检查一次

### 当前版本信息

| 信息 | 说明 |
|------|------|
| 当前版本 | 您正在使用的 AgentSec 版本 |
| 最新版本 | GitHub Release 上的最新版本 |
| 上次检查 | 上次检查更新的时间 |

### 手动检查更新

点击 **「立即检查更新」** 按钮，实时查询最新版本。

检测到新版本后：
- 设置页面显示新版本详情 + 发布说明
- 仪表盘顶部弹出更新横幅
- 点击「下载并安装」自动下载和安装（Windows）/ 打开 DMG（macOS）

> 📸 **[截图位置]** `screenshots/settings-appearance.png` — 外观设置截图

### 主题

- **深色模式**：开关切换
- 默认跟随系统偏好（`prefers-color-scheme`）

### 界面语言

支持三种语言：
- 简体中文（默认）
- 繁體中文
- English

切换后整个界面立即生效，AI 助手也会自动切换回复语言。

## 五、版本说明

> 📸 **[截图位置]** `screenshots/settings-version.png` — 版本说明截图

显示版本更新历史（Changelog），从 v1.0.0 到当前版本，按版本倒序排列。

每条更新记录标注类型：
- `feat`（绿色）— 新功能
- `fix`（红色）— 问题修复
- `improve`（绿色）— 改进优化
- `ui`（黄色）— 界面调整
