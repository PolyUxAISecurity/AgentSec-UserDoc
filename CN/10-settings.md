# 设置与账户指南

> 设置页面用于管理 AgentSec 的所有配置：常规、安全配置、账户、AI 模型、自动更新等。

---

## 打开设置

点击侧边栏底部的 **⚙ 设置** 按钮。

![待补：新版设置分类导航全景](./screenshots/pending.svg)

---

## 设置页面布局

设置页采用**左右分类导航**布局：左侧用于切换常规、安全配置、账户、更新、外观和版本等分类，右侧显示当前分类的具体设置项。

### ⚡ 自动保存

设置改动会自动保存；监控和运行时防护开关立即生效。页面没有单独的底部保存按钮。

## 一、常规

![待补：常规设置、运行模式与 Agent Island](./screenshots/pending.svg)

### 配置向导

点击 **「运行引导向导」** 可以重新运行首次配置向导。适合想要重新设置使用方式或监控目录的情况。

### 运行模式

| 模式                 | 说明                         |
| ------------------ | -------------------------- |
| Local（离线本地） | 不登录 AgentSec；规则在本机运行。AI 可选，使用您配置的模型服务 |
| Community（云端 SaaS） | 登录 AgentSec 云服务，使用组织提供的模型服务 |

![待补：本地模式和可选 AI 模型配置](./screenshots/pending.svg)

切换模式后，下方会显示对应的提示和配置项。

本地模式的 **AI 研判模型（可选）** 位于此处。选择供应商、模型和所需的 API Key；使用 Ollama 或 OpenAI 兼容服务时，可填写自定义 Base URL。点击 **测试 LLM** 核对连接。不配置模型仍可使用规则扫描。企业内网部署按管理员提供的服务器与账号连接。

### 新手引导、通知与高级模式

- **Agent Island**：开启桌面顶部可拖动的悬浮状态岛，查看监控和分析进度，点击可恢复主窗口；默认关闭。
- **新手引导**：重新观看界面介绍。
- **通知提醒级别**：选择全部、警告及以上、仅错误或关闭弹出提醒；通知仍可在威胁中心查看。
- **高级模式 → 显示 DSL 自定义规则**：开启后，Engine 侧栏显示「DSL 规则」入口。关闭仅隐藏入口，已保存的规则仍按当前状态运行。

### 开发者选项

- **启用 Debug 视图**：开启后侧边栏出现「Debug」入口，可查看实时分析日志流
- 仅在排查问题时需要开启

Debug 的 **Git 保管库** 可查看内容快照的提交日志、追踪文件和内容差异；**实时日志** 可查看、清空或导出日志。这些入口只在启用 Debug 后显示，日常监控和审计无需开启。

### 危险区域

**「重置所有数据」** 按钮会：
- 清空配置、Agent ID、分析历史、聊天记录、白名单
- 删除完成后应用自动退出
- 重新打开时如同首次安装

> ⚠️ 此操作不可撤销！

## 二、安全配置

![待补：安全配置页面及新增功能](./screenshots/pending.svg)

### DeepIntent Agent 工作区

点击 **导入待修复脚本**，把需要助手读取或修改的脚本副本放入工作区；点击 **打开工作区** 查看文件。助手的文件工具只访问该工作区，监控目录不会扩大其读写范围，原始脚本不会因导入而修改。

![待补：DeepIntent Agent 工作区](./screenshots/pending.svg)

_截图待补：工作区路径、导入待修复脚本与打开工作区按钮。_

### 运行时防护与 Agent 接入

开启 **运行时防护** 后，可记录内置 DeepIntent Agent 的活动及工具调用审计。外部 Agent 需要在下方 **Agent 目录检测** 中接入：

1. 点击 **重新检测**，查看已安装的 Claude Code、OpenCode、Codex、Gemini 或 Qwen。
2. 为需要接入的 Agent 打开部署开关。
3. 部署或重新部署后，重启正在运行的外部 Agent。
4. 到 **安全仪表盘 → Agent 监控** 和 **威胁中心 → Agent 实时事件** 查看记录。

内置 DeepIntent Agent 自动接入，界面标为「仅审计」。外部 Agent 仅对已接入且受支持的工具调用实施防护。**超时处置** 可选「拒绝（默认）」或「放行并留痕」。

![待补：运行时防护与 Agent 目录检测](./screenshots/pending.svg)

_截图待补：运行时防护开关、超时处置及已检测 Agent 的部署状态。_

### 监控开关

使用 **监控开关** 卡片可以启动或停止脚本监控。关闭后，AgentSec 不再实时分析目录中新建或修改的 RPA 脚本；重新开启即可恢复监控。

### 监控目录

支持**多目录同时监控**。可以通过以下方式添加需要保护的 RPA 脚本目录：

- 在输入框中填写路径并按回车
- 点击 **「添加目录」** 打开目录选择器，可一次选择多个目录
- 点击 **「搜索本机」** 检测常见 RPA 工具的脚本目录

搜索到的目录会显示在 **「检测到的 RPA 目录」** 中，并标注工具名称、路径和脚本数量。检测结果不会自动加入监控，需要确认后才会生效。

删除监控目录前会显示确认。确认后会清理该目录的本地分析、信任和内容快照记录；磁盘上的脚本和隔离副本会保留，需要时先在安全沙箱处理隔离文件。

#### 启动即开启监控

启用后，AgentSec 启动时会自动监控已配置且当前存在的目录，无需每次手动启动。未配置监控目录或目录已不存在时，不会自动开启监控。

### 隐私与安全

#### 敏感凭据密文显示

默认开启。上传脚本或使用 AI 问答时，凭据会在离开本机及显示到界面前替换为不可逆占位符，避免 API Key、密码等敏感信息被直接展示或发送；本地脚本原文不会被修改。

### 分析引擎

#### 规则引擎（DSL 规则集）

规则引擎**始终启用**，负责进行确定性规则匹配。分析在本地以毫秒级完成，不依赖网络或大型模型；命中规则后，AgentSec 会按照规则给出风险结论和处置建议。

规则可以通过两种方式更新：

- **从 Console 更新规则**：连接 Console 获取最新规则
- **导入规则更新包（离线）**：适用于内网或无法连接 Console 的环境，由管理员导出签名规则包后在此导入

#### AI 研判（可选）

AI 研判用于理解脚本意图，补充识别规则暂未覆盖的风险。关闭后，脚本正文不会因 AI 研判离开本机，分析结论仅由规则引擎给出。

## 四、更新

![待补：版本更新、上次检查与更新 API 地址](./screenshots/pending.svg)

### 自动检查更新

- **开关**：启用/禁用启动时和周期性的自动更新检查
- **默认**：启用，每 6 小时检查一次

### 当前版本信息

| 信息 | 说明 |
|------|------|
| 当前版本 | 您正在使用的 AgentSec 版本 |
| 最新版本 | GitHub Release 上的最新版本 |
| 上次检查 | 上次检查更新的时间 |

**更新 API 地址** 由默认服务或部署管理员提供；按当前部署使用相应地址。

### 手动检查更新

点击 **「立即检查更新」** 按钮，实时查询最新版本。

检测到新版本后：
- 设置页面显示新版本详情 + 发布说明
- 仪表盘顶部弹出更新横幅
- 点击「下载并安装」自动下载和安装（Windows）/ 打开 DMG（macOS）

## 五、外观

![待补：界面大小、主题、配色风格及语言](./screenshots/pending.svg)

### 界面大小

拖动滑块或点击加减按钮调整整个界面，范围为 50%–200%；点击 **恢复 100%** 还原。也可使用 `Ctrl` / `⌘` 配合 `+`、`−`、`0`。修改立即生效并自动保存。

### 主题

- **深色模式**：开关切换
- 默认跟随系统偏好（`prefers-color-scheme`）

### 配色风格

可选 **极简单色** 或 **AgentSec 绿**。

### 界面语言

支持三种语言：
- 简体中文（默认）
- 繁體中文
- English

切换后整个界面立即生效，AI 助手也会自动切换回复语言。
