# 仪表盘使用指南

> 仪表盘是您打开 AgentSec 后看到的第一个页面，集中展示监控状态、风险概览和统计数据。

---

## 仪表盘布局

> 📸 **[截图位置]** `screenshots/dashboard-full.png` — 仪表盘全景截图

仪表盘分为以下几个区域：

```
┌─────────────────────────────────────────────┐
│  ┌──────────────────────────────────────┐   │
│  │  状态区                               │   │
│  │  ● 监控中 | AI 分析中...              │   │
│  │  风险概览: HIGH  │  [启动监控]        │   │
│  │  📁 监控目录: C:\Users\...\UiPath     │   │
│  └──────────────────────────────────────┘   │
│                                             │
│  ┌─ 今日动态 ────────────────────────────┐  │
│  │  拦截数: 2 (建议拦截执行的脚本数)      │  │
│  └───────────────────────────────────────┘  │
│                                             │
│  ┌─ AI 分析流水线 ──────────────────────┐   │
│  │  5 脚本 → 1 分析中 → 3 已分析 → 0 失败│  │
│  │  → 2 白名单                           │   │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

## 一、状态区

> 📸 **[截图位置]** `screenshots/dashboard-status-area.png` — 状态区放大截图

状态区显示 AgentSec 当前的工作状态：

| 状态 | 样式 | 含义 |
|------|------|------|
| 监控中 | 绿色圆点 + 脉冲动画 | 正在实时监控脚本变化 |
| 已连接 | 绿色圆点（静态） | 已登录服务端，但监控未启动 |
| 未连接 | 灰色圆点 | 未登录或服务端不可达 |

**状态文字说明：**

| 显示内容 | 对应情况 |
|---------|---------|
| 「AI 分析中...」 | 登录模式或本地模式正在运行 |
| 「本地模式已就绪」 | 本地模式，LLM 配置正常 |
| 「LLM 未配置」 | 本地模式，尚未配置 AI 模型 |
| 「等待连接 AgentSec 服务器...」 | 登录模式，但未登录或服务端不可达 |

### 风险概览

> 📸 **[截图位置]** `screenshots/dashboard-risk-overview.png` — 风险概览卡片

显示所有已分析脚本中的**最高风险等级**和**问题总数**：

| 风险等级 | 颜色 | 含义 |
|---------|------|------|
| `CRITICAL` | 红色 | 发现严重安全问题（如数据外泄、硬编码密码） |
| `HIGH` | 橙色 | 发现高危问题（如 HTTP 明文传输、禁用证书校验） |
| `MEDIUM` | 黄色 | 发现中危问题（如异常处理缺失、输入未校验） |
| `LOW` | 灰色 | 仅低危建议或未发现问题 |

> 💡 **风险概览是可点击的**。点击它会跳转到防护日志，方便快速查看详情。

### 监控目录卡片

> 📸 **[截图位置]** `screenshots/dashboard-watchdir-card.png` — 监控目录卡片

- **已配置**：显示当前监控的目录路径
- **未配置**：显示黄色警告「未配置 · 点击设置」
- **点击**：跳转到设置页面并自动定位到目录选择框

## 二、今日动态 — 拦截数

> 📸 **[截图位置]** `screenshots/dashboard-blocked-count.png` — 拦截数卡片

**拦截数** = 所有已分析脚本中被标记为「需要拦截」的数量。

- 红色数字 = 有脚本被拦截
- **点击此卡片** → 跳转到安全沙箱页面，查看被拦截的文件

---

## 三、AI 分析流水线

> 📸 **[截图位置]** `screenshots/dashboard-pipeline.png` — 分析流水线截图

流水线用箭头展示脚本从发现到完成的全过程：

```
脚本数  ──→  分析中  ──→  已分析  ──→  分析失败  ──→  白名单
 (5)         (1)         (3)          (0)          (2)
```

| 指标 | 含义 |
|------|------|
| **脚本数** | 监控目录中发现的脚本文件总数 |
| **分析中** | 正在等待 AI 分析的脚本数 |
| **已分析** | 已完成 AI 分析的脚本数 |
| **分析失败** | AI 分析出错的脚本数（可能是文件损坏或模型超时） |
| **白名单** | 从隔离区还原后加入信任列表的脚本数 |

> 💡 每个数字都是可点击的，点击可快速跳转到对应页面。

---

## 四、侧边栏状态

> 📸 **[截图位置]** `screenshots/sidebar-status.png` — 侧边栏状态区域

侧边栏顶部有一个状态按钮，显示当前的连接状态：

- **监控中**：绿色闪烁圆点 — 一切正常
- **已连接**：绿色圆点 — 已登录但未开始监控
- **未连接**：红色圆点 — 未登录或网络异常
- **已封禁**：红色圆点 + 「已封禁」文字 — 组织被管理员封禁

> 📸 **[截图位置]** `screenshots/sidebar-banned.png` — 被封禁时的侧边栏状态

登录后，侧边栏底部还会显示：
- **组织用量**：当前组织的 AI 调用配额使用情况（进度条 + 百分比）
- **用户信息**：登录邮箱 + 头像

## 五、AI Copilot 快捷入口

> 📸 **[截图位置]** `screenshots/fab-button.png` — 右下角的 AI 助手 FAB 按钮

仪表盘右下角有一个 **AI 助手浮动按钮**（FAB），标注「AI 助手」+ 快捷键提示。

- **点击 FAB**：打开 AI 安全助手面板
- **快捷键 `Ctrl+K`**（Windows）/ `Cmd+K`（macOS）：开关 AI 助手面板

详见 [AI 安全助手使用指南](ai-assistant.md)。

## 六、顶部更新横幅

> 📸 **[截图位置]** `screenshots/update-banner.png` — 有新版本时的顶部横幅

当检测到新版本时，仪表盘顶部会出现更新横幅：

- 显示最新版本号
- 「下载并安装」按钮（Windows 支持一键安装）
- 「前往下载」按钮（跳转 GitHub Release 页面）
- 右侧 ✕ 可关闭横幅
