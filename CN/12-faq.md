# 常见问题

## 开始使用

### 必须登录或配置模型才能扫描吗？

不必。本地模式不需要登录，也可不配置模型；规则引擎仍会检查脚本。使用 AI 研判或 AI 助手时，需要登录使用组织的模型服务，或在 **设置 → 常规 → 运行模式** 配置自己的模型。

### 如何重新打开首次配置？

进入 **设置 → 常规**，点击 **运行引导向导**。如果只是想重新观看界面介绍，可使用同页的 **新手引导**。

### 本地模式是否一定不联网？

规则扫描在本机完成。AI 是否联网取决于模型：本机 Ollama 可本地推理，OpenAI 等远程服务需要联网，并会接收 AI 请求。

## 脚本监控

### 开启监控后，在哪里看结果？

到 **威胁中心 → 脚本威胁列表** 查看文件与详情；**安全仪表盘 → 安全总览** 也会汇总脚本结果。监控目录应包含支持的脚本类型，且不能位于自动排除的目录中。

### 可以同时监控多个目录吗？

可以。在 **设置 → 安全配置 → 监控目录** 添加多个文件夹。检测到的 RPA 目录需您确认后才加入监控。

### 为什么规则结果先出现，AI 还在运行？

规则与 AI 分别显示进度。规则通常较快，AI 时间取决于脚本、模型和服务响应。查看具体报告中的引擎状态即可确认本次完成了哪些检查；AI 关闭时只显示规则结果。

### 高危是否代表已经隔离？

不一定。风险等级是分析结论，隔离状态是实际操作。默认处置下，仅由 AI 得出的拦截建议需要人工确认。请在详情中复核证据和待确认提示，再决定是否隔离。

### 确认是安全脚本后如何恢复？

在 **威胁中心 → 安全沙箱** 选中文件，复核后使用信任或还原操作。需要先修改脚本时，可使用整改区检查修改后的内容，再确认还原。详见 [安全沙箱](06-sandbox.md)。

### 「放行」或「未发现问题」是否代表绝对安全？

它表示本次检查未得到需要拦截或警告的结论。仍需结合规则范围、AI 完成情况和实际业务复核。

## Dify

### Dify 工作流需要放进监控目录吗？

不需要。从 **AgentSec Engine™ → 规则实验室 → Dify 工作流** 获取或导入工作流。可选择 **本地直连、组织连接、文件与演示**；报告归档在 **威胁中心 → Dify 工作流**。详见 [Dify 指南](dify.md)。

### Dify 整改后，点击重新分析快照就够了吗？

重新分析快照检查的是保存过的内容。要检查新草稿或新发布版本，应从获取入口重新获取；文件方式应导入修改后的 DSL，再查看整改复测对比。

## Agent 与助手

### 为什么 Agent 监控里还没有事件？

先在 **设置 → 安全配置** 开启运行时防护。外部 Agent 还需在 **Agent 目录检测** 部署接入并重启。产生受支持的工具调用后，相关记录才会出现；纯文本对话不计为工具事件。

### 助手可以直接修改我的监控目录吗？

助手文件工具只访问受管理工作区。请在 **设置 → 安全配置 → DeepIntent Agent 工作区** 点击 **导入待修复脚本**，让助手处理导入副本。原始目录不因加入监控而开放给助手读写。

### 在哪里配置或测试本地模型？

进入 **设置 → 常规 → 运行模式**，选择本地模式后填写模型配置，点击 **测试 LLM**。登录模式使用组织提供的模型服务。

## 设置与更新

### 如何调整界面大小？

进入 **设置 → 外观 → 界面大小**，或使用 `Ctrl` / `⌘` 配合 `+`、`−`、`0`。

### 如何更新客户端？

进入 **设置 → 更新**，点击 **立即检查更新**。发现新版本后按页面的 **下载并安装** 或 **前往下载** 操作。macOS 打开 DMG 后，将应用拖入 Applications 完成替换。

### 导出日志会包含脚本原文吗？

分析记录导出会移除脚本原文字段；ZIP 还包含选中的运行日志、对话等记录。Dify 报告请使用对应报告的脱敏导出入口。

### 如何重置应用数据？

进入 **设置 → 常规 → 危险区域 → 重置所有数据**。确认后清空配置、身份、分析历史、对话和信任记录等本地数据，应用自动退出。此操作不可撤销；重新打开后需重新配置。
