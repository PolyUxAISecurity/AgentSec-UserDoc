# 关键概念解释

## 三类使用场景

| 场景 | 检查对象 | 查看位置 |
| --- | --- | --- |
| **脚本监控** | 监控目录内新增、修改的 RPA 脚本 | 威胁中心 → 脚本威胁列表 |
| **Agent 运行时防护** | 已接入 Agent 的受支持工具调用 | Agent 监控、威胁中心 → Agent 实时事件 |
| **Dify 工作流审计** | 获取或导入的工作流快照 | 规则实验室、威胁中心 → Dify 工作流 |

Dify 审计检查工作流快照中的潜在风险，不执行工作流，也不直接阻止 Dify Cloud 运行。内置 DeepIntent Agent 的运行时接入用于活动记录与工具调用后审计；外部 Agent 的防护取决于其接入方式和支持范围。

## 监控与分析

### 监控目录

需要 AgentSec 检查的脚本文件夹，可同时添加多个。启用监控后，新建或修改文件会触发检查，受排除目录、支持文件类型和信任状态等条件影响。

### 规则引擎

在本机匹配已知风险模式，始终运行，不需要配置 AI 模型。规则包可从 Console 更新，也可导入管理员提供的离线更新包。

### AI 研判

可选的补充分析，用于理解脚本或工作流意图、解释风险。是否运行、是否完成和使用的引擎会显示在结果中。模型未配置或 AI 关闭时，规则扫描仍可工作。

### 风险等级与分数

等级包括 **严重（Critical）**、**高危（High）**、**中危（Medium）** 和 **低危（Low）**；分数通常以 0–100 表示，数值越高越值得优先复核。请结合具体问题、证据和覆盖情况阅读，分数不是业务安全保证。

### 分析结论与实际处置

**拦截建议** 是分析结果；**已隔离** 或运行时 **已阻断** 表示实际执行的动作。两者需要分开查看。

默认脚本处置方式会对确定性规则的高危判定自动处置，对仅由 AI 得出的拦截建议保留人工确认。若看到待确认提示，应先复核证据，再选择是否隔离。

## 脚本处置

### 隔离与安全桩

隔离会把原脚本保存在同级的 `.agentsec_quarantine` 目录，并在原路径放置安全桩。安全桩用于说明隔离原因，替代原来的业务脚本。隔离文件可在 **威胁中心 → 安全沙箱** 管理。

### 信任列表

确认脚本安全后，可通过界面信任或还原文件。AgentSec 按文件内容指纹识别已信任版本；内容变化后需要重新检查。

### 整改区

用于修改隔离文件的副本并检查整改结果。完成复核后，由用户确认还原。详见 [安全沙箱](06-sandbox.md)。

### 内容保管库

保存脚本内容快照，供回看与重新分析使用。重新分析已有快照，不等于重新获取外部系统中的最新内容；Dify 整改后应重新获取或导入新版本。

## 运行模式与模型

| 模式 | 含义 |
| --- | --- |
| **Community** | 连接 AgentSec 云服务，使用组织提供的模型服务 |
| **On-Premise** | 连接企业自建的 AgentSec 服务，按管理员要求配置 |
| **Local** | 不登录 AgentSec；规则在本机运行，AI 可使用自己的本机或远程模型 |

「本地模式」表示客户端不依赖 AgentSec 登录服务，不代表配置的远程模型也在本机运行。使用 OpenAI 等远程模型会向该服务发送 AI 请求；使用本机 Ollama 模型时，推理在本机完成。

## Agent 与助手

### DeepIntent Agent

内置 AI 安全助手，可解读结果、调用工具和处理工作区内的脚本副本。纯文本回复不计为工具调用事件。

### 工作区

助手文件工具可访问的受管理目录。在 **设置 → 安全配置 → DeepIntent Agent 工作区** 导入待修复脚本后，助手处理导入副本；监控目录不会扩大助手的读写范围。

### 外部 Agent 接入

通过 **设置 → 安全配置 → Agent 目录检测** 为支持的外部 Agent 部署防护接入。部署后需要重启正在运行的外部 Agent。只有已接入的受支持工具调用会产生相应防护记录。

### 工具调用

助手执行查询状态、配置检查或工作区文件操作等任务。对话中的工具卡片显示调用和结果，可据此核对实际完成的操作。日志需在客户端界面手动导出。

## 策略与记录

### 安全策略与策略市场

安全策略决定检查规则、风险等级与建议动作。通过 **AgentSec Engine™ → 引擎** 查看模块和配置，通过 **策略市场** 查看并使用适合业务的策略；组织托管的配置可能由管理员管理。

### 威胁中心

集中查看 **脚本威胁列表、Agent 实时事件、Dify 工作流、历史记录、通知、安全沙箱**。不同类型的结果保留各自的检查对象和处置状态。

### Agent ID 与登录身份

Agent ID 用于区分设备。登录后客户端加入对应组织；账户与组织信息可在 **设置 → 账户** 查看。

### 日志导出

将分析记录、运行日志和对话记录等保存为 ZIP，便于归档或与支持人员交流。分析记录导出会移除脚本原文字段；Dify 审计另有脱敏报告导出入口。
