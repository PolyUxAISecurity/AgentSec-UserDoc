# 關鍵概念解釋

## 三類使用場景

| 場景 | 檢查對象 | 查看位置 |
| --- | --- | --- |
| **腳本監控** | 監控目錄內新增、修改的 RPA 腳本 | 威脅中心 → 腳本威脅列表 |
| **Agent 運行時防護** | 已接入 Agent 的受支持工具調用 | Agent 監控、威脅中心 → Agent 實時事件 |
| **Dify 工作流審計** | 獲取或導入的工作流快照 | 規則實驗室、威脅中心 → Dify 工作流 |

Dify 審計檢查工作流快照中的潛在風險，不執行工作流，也不直接阻止 Dify Cloud 運行。內置 DeepIntent Agent 的運行時接入用於活動記錄與工具調用後審計；外部 Agent 的防護取決於其接入方式和支持範圍。

## 監控與分析

### 監控目錄

需要 AgentSec 檢查的腳本文件夾，可同時添加多個。啓用監控後，新建或修改文件會觸發檢查，受排除目錄、支持文件類型和信任狀態等條件影響。

### 規則引擎

在本機匹配已知風險模式，始終運行，不需要配置 AI 模型。規則包可從 Console 更新，也可導入管理員提供的離線更新包。

### AI 研判

可選的補充分析，用於理解腳本或工作流意圖、解釋風險。是否運行、是否完成和使用的引擎會顯示在結果中。模型未配置或 AI 關閉時，規則掃描仍可工作。

### 風險等級與分數

等級包括 **嚴重（Critical）**、**高危（High）**、**中危（Medium）** 和 **低危（Low）**；分數通常以 0–100 表示，數值越高越值得優先複覈。請結合具體問題、證據和覆蓋情況閱讀，分數不是業務安全保證。

### 分析結論與實際處置

**攔截建議** 是分析結果；**已隔離** 或運行時 **已阻斷** 表示實際執行的動作。兩者需要分開查看。

默認腳本處置方式會對確定性規則的高危判定自動處置，對僅由 AI 得出的攔截建議保留人工確認。若看到待確認提示，應先複覈證據，再選擇是否隔離。

## 腳本處置

### 隔離與安全樁

隔離會把原腳本保存在同級的 `.agentsec_quarantine` 目錄，並在原路徑放置安全樁。安全樁用於說明隔離原因，替代原來的業務腳本。隔離文件可在 **威脅中心 → 安全沙箱** 管理。

### 信任列表

確認腳本安全後，可通過界面信任或還原文件。AgentSec 按文件內容指紋識別已信任版本；內容變化後需要重新檢查。

### 整改區

用於修改隔離文件的副本並檢查整改結果。完成複覈後，由用戶確認還原。詳見 [安全沙箱](06-sandbox.md)。

### 內容保管庫

保存腳本內容快照，供回看與重新分析使用。重新分析已有快照，不等於重新獲取外部系統中的最新內容；Dify 整改後應重新獲取或導入新版本。

## 運行模式與模型

| 模式 | 含義 |
| --- | --- |
| **Community** | 連接 AgentSec 雲服務，使用組織提供的模型服務 |
| **On-Premise** | 連接企業自建的 AgentSec 服務，按管理員要求配置 |
| **Local** | 不登錄 AgentSec；規則在本機運行，AI 可使用自己的本機或遠程模型 |

「本地模式」表示客戶端不依賴 AgentSec 登錄服務，不代表配置的遠程模型也在本機運行。使用 OpenAI 等遠程模型會向該服務發送 AI 請求；使用本機 Ollama 模型時，推理在本機完成。

## Agent 與助手

### DeepIntent Agent

內置 AI 安全助手，可解讀結果、調用工具和處理工作區內的腳本副本。純文本回復不計爲工具調用事件。

### 工作區

助手文件工具可訪問的受管理目錄。在 **設置 → 安全配置 → DeepIntent Agent 工作區** 導入待修復腳本後，助手處理導入副本；監控目錄不會擴大助手的讀寫範圍。

### 外部 Agent 接入

通過 **設置 → 安全配置 → Agent 目錄檢測** 爲支持的外部 Agent 部署防護接入。部署後需要重啓正在運行的外部 Agent。只有已接入的受支持工具調用會產生相應防護記錄。

### 工具調用

助手執行查詢狀態、配置檢查或工作區文件操作等任務。對話中的工具卡片顯示調用和結果，可據此覈對實際完成的操作。日誌需在客戶端界面手動導出。

## 策略與記錄

### 安全策略與策略市場

安全策略決定檢查規則、風險等級與建議動作。通過 **AgentSec Engine™ → 引擎** 查看模塊和配置，通過 **策略市場** 查看並使用適合業務的策略；組織託管的配置可能由管理員管理。

### 威脅中心

集中查看 **腳本威脅列表、Agent 實時事件、Dify 工作流、歷史記錄、通知、安全沙箱**。不同類型的結果保留各自的檢查對象和處置狀態。

### Agent ID 與登錄身份

Agent ID 用於區分設備。登錄後客戶端加入對應組織；賬戶與組織信息可在 **設置 → 賬戶** 查看。

### 日誌導出

將分析記錄、運行日誌和對話記錄等保存爲 ZIP，便於歸檔或與支持人員交流。分析記錄導出會移除腳本原文字段；Dify 審計另有脫敏報告導出入口。
