# 常見問題

## 開始使用

### 必須登錄或配置模型才能掃描嗎？

不必。本地模式不需要登錄，也可不配置模型；規則引擎仍會檢查腳本。使用 AI 研判或 AI 助手時，需要登錄使用組織的模型服務，或在 **設置 → 常規 → 運行模式** 配置自己的模型。

### 如何重新打開首次配置？

進入 **設置 → 常規**，點擊 **運行引導向導**。如果只是想重新觀看界面介紹，可使用同頁的 **新手引導**。

### 本地模式是否一定不聯網？

規則掃描在本機完成。AI 是否聯網取決於模型：本機 Ollama 可本地推理，OpenAI 等遠程服務需要聯網，並會接收 AI 請求。

## 腳本監控

### 開啓監控後，在哪裏看結果？

到 **威脅中心 → 腳本威脅列表** 查看文件與詳情；**安全儀表盤 → 安全總覽** 也會彙總腳本結果。監控目錄應包含支持的腳本類型，且不能位於自動排除的目錄中。

### 可以同時監控多個目錄嗎？

可以。在 **設置 → 安全配置 → 監控目錄** 添加多個文件夾。檢測到的 RPA 目錄需您確認後才加入監控。

### 爲什麼規則結果先出現，AI 還在運行？

規則與 AI 分別顯示進度。規則通常較快，AI 時間取決於腳本、模型和服務響應。查看具體報告中的引擎狀態即可確認本次完成了哪些檢查；AI 關閉時只顯示規則結果。

### 高危是否代表已經隔離？

不一定。風險等級是分析結論，隔離狀態是實際操作。默認處置下，僅由 AI 得出的攔截建議需要人工確認。請在詳情中複覈證據和待確認提示，再決定是否隔離。

### 確認是安全腳本後如何恢復？

在 **威脅中心 → 安全沙箱** 選中文件，複覈後使用信任或還原操作。需要先修改腳本時，可使用整改區檢查修改後的內容，再確認還原。詳見 [安全沙箱](06-sandbox.md)。

### 「放行」或「未發現問題」是否代表絕對安全？

它表示本次檢查未得到需要攔截或警告的結論。仍需結合規則範圍、AI 完成情況和實際業務複覈。

## Dify

### Dify 工作流需要放進監控目錄嗎？

不需要。從 **AgentSec Engine™ → 規則實驗室 → Dify 工作流** 獲取或導入工作流。可選擇 **本地直連、組織連接、文件與演示**；報告歸檔在 **威脅中心 → Dify 工作流**。詳見 [Dify 指南](dify.md)。

### Dify 整改後，點擊重新分析快照就夠了嗎？

重新分析快照檢查的是保存過的內容。要檢查新草稿或新發布版本，應從獲取入口重新獲取；文件方式應導入修改後的 DSL，再查看整改複測對比。

## Agent 與助手

### 爲什麼 Agent 監控裏還沒有事件？

先在 **設置 → 安全配置** 開啓運行時防護。外部 Agent 還需在 **Agent 目錄檢測** 部署接入並重啓。產生受支持的工具調用後，相關記錄纔會出現；純文本對話不計爲工具事件。

### 助手可以直接修改我的監控目錄嗎？

助手文件工具只訪問受管理工作區。請在 **設置 → 安全配置 → DeepIntent Agent 工作區** 點擊 **導入待修復腳本**，讓助手處理導入副本。原始目錄不因加入監控而開放給助手讀寫。

### 在哪裏配置或測試本地模型？

進入 **設置 → 常規 → 運行模式**，選擇本地模式後填寫模型配置，點擊 **測試 LLM**。登錄模式使用組織提供的模型服務。

## 設置與更新

### 如何調整界面大小？

進入 **設置 → 外觀 → 界面大小**，或使用 `Ctrl` / `⌘` 配合 `+`、`−`、`0`。

### 如何更新客戶端？

進入 **設置 → 更新**，點擊 **立即檢查更新**。發現新版本後按頁面的 **下載並安裝** 或 **前往下載** 操作。macOS 打開 DMG 後，將應用拖入 Applications 完成替換。

### 導出日誌會包含腳本原文嗎？

分析記錄導出會移除腳本原文字段；ZIP 還包含選中的運行日誌、對話等記錄。Dify 報告請使用對應報告的脫敏導出入口。

### 如何重置應用數據？

進入 **設置 → 常規 → 危險區域 → 重置所有數據**。確認後清空配置、身份、分析歷史、對話和信任記錄等本地數據，應用自動退出。此操作不可撤銷；重新打開後需重新配置。
